# Aurelius Real Estate — v2

One-page landing site for Aurelius Real Estate (Dubai off-plan property), design **v2**.

Swiss grid, expanded grotesk type, split hero with a masked photo reveal, square corners, glass-blue accent.

- Catalog: Galleria Residences by Evera (Dubai South) — photos, overview, 13 floor plans with m² / sq ft.
- Prices and brochure downloads unlock after the enquiry form is sent.
- Enquiries go to Gmail via FormSubmit (`klibraeva80@gmail.com`). After the first test enquiry, confirm the "Activate form" email once.

**Deploy:** Cloudflare → Workers & Pages → Create → connect this repository. No build command, output directory `/`.
